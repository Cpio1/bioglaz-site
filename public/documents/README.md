# Свидетельство о государственной регистрации

Положите сюда скан или фотографию свидетельства № AM.01.07.01.003.R.001007.12.25 от 19.12.2025.

- `certificate.webp` / `certificate.png` / `certificate.jpg` / `certificate.jpeg` — изображение для просмотра на сайте.
- `certificate.pdf` — (необязательно) PDF-оригинал, на него появится ссылка «Открыть PDF».

После добавления файла пересоберите проект (`npm run build`).
