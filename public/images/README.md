# Фотографии продукта

Положите сюда настоящие фотографии баночки БИОГЛАЗ. Сайт найдёт их автоматически при сборке
(проверяются имена ниже, по порядку; используется первый найденный файл).

1. `bioglaz-jar-transparent.png` / `bioglaz-jar-transparent.webp` — баночка на прозрачном фоне (лучший вариант).
2. `bioglaz-jar.webp` / `bioglaz-jar.png` / `bioglaz-jar.jpg` / `bioglaz-jar.jpeg` — исходная фотография с фоном
   (будет показана в аккуратной светлой рамке, без обрезки и искажений).

Рекомендуемое разрешение: от 1600 px по длинной стороне.
